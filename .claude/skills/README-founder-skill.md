# Skills de venta (founder-skill)

6 de las 11 skills de [Jakeschincariol/founder-skill](https://github.com/Jakeschincariol/founder-skill)
(commit `fd9385b`, licencia MIT, ver `LICENSE-founder-skill`). Para usar en otro proyecto:
copiar las carpetas `founder-*` a `.claude/skills/` de ese repo.

Orden sugerido: `/founder-competitors` → `/founder-consumer --quick` → `/founder-pricing`
→ `/founder-offer` → `/founder-marketing` → `/founder-launch`. Escriben sus resultados en `founder/`.

No incluidas: board, cfo, brand, ops, plan. Algunas skills las mencionan:
- `founder-offer` usa `../founder-board/lenses.md` (método de ofertas).
- `founder-pricing` usa `../founder-cfo/unit_economics.py` y `founder/numbers.json` para el margen.
Sin ellas funcionan, pero sin el cálculo de margen ni el método de ofertas.

Los "compradores" de `/founder-consumer` son simulados: sirven para encontrar objeciones,
no para predecir ventas reales.
